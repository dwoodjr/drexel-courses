# ASN 3: Experimental Media Project
**Weight:** 35%

---
## Overview

Develop an original digital media project that demonstrates **thinking-in-action**. Projects are encouraged to utilize physical computing hardware entangled with software environments. Evaluated on the rigor of the path taken, not just final polish.

## Spirit of the Assignment
This is not a "make a cool thing" assignment. It is a research-creation project: the making process *is* the research. The project should demonstrate how your encounter with tools and materials transformed your initial inquiry. The project should show evidence of risk, impasse, pivot, and transformation.

## Hardware and Software
Projects should engage with at least one physical computing element (Adafruit QT Py RP2040, MPR121 touch sensor, or equivalent) entangled with a software environment (TouchDesigner, Max/MSP, p5.js, Pure Data, Unity, or equivalent).

## Milestones

### Initial Prototyping (Weeks 1–4)
Early explorations feeding into the Speculative Proposal.

### Mid-term Status (Week 7)
Mid-term presentation focuses on what *isn't working* and what that reveals. Not a polish presentation — an honest reckoning with impasse.

### Final Submission (Week 10/11)
Final build + documentation uploaded to Blackboard. Documentation should include: project description, process narrative, technical documentation, and reflection on how the project changed from proposal to completion.

## Evaluation Criteria
Creative risk, conceptual-material integration, technical engagement, research-creation methodology.
