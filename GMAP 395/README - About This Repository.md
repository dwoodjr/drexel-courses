## Overview

This repository contains the complete course materials for GMAP 395: Advanced Game Art and Production, designed around a **modular, semi-self-paced learning approach**. The course materials are built using **[Obsidian](https://obsidian.md/)** as a knowledge management system and are deployed as a self-hosted website via **GitHub Pages**.

**Live Course Site:** https://dwoodjr.github.io/drexel-courses/gmap-395/gmap-395-welcome.html

## Repository Structure & Philosophy

### Core Approach

This course implements a **modular learning framework** that transforms traditional lecture-heavy instruction into focused, digestible learning modules. The approach emphasizes:

- **Studio-based learning** with hands-on practice
- **Peer critique systems** replacing traditional quizzes
- **Flexible pacing** within structured frameworks

### Technology Stack

- **Backend:** Obsidian vault with markdown files
- **Frontend:** GitHub Pages deployment
- **Content Format:** Markdown with embedded media (videos, images, links)
- **Navigation:** Bidirectional linking between course components

### Naming Conventions

#### File Naming Pattern

```
GMAP 395 - [Type] [Number][Letter] - [Descriptive Title].md
```

**Examples:**

- `GMAP 395 - Module 1.md` (main module page)
- `GMAP 395 - Module 1A - Game Feel and Tactile Experience.md` (submodule)
- `GMAP 395 - ASN 1 - Brief.md` (assignment brief)
- `GMAP 395 - WK 2 - Tutorial.md` (tutorial content)

#### Content Type Indicators

- **Module `[#]`:** Main module overview page
- **Module `[#][Letter]`:** Individual submodule (replaces traditional lectures)
- **ASN `[#]`:** Assignment brief and requirements
- **WK `[#]`:** Week-specific tutorials or activities
- **Guide:** Comprehensive reference materials
- **Weekly `[#]`:** Progress check and critique activities

## Module Structure Explained

### Module Components

#### 1. Module Overview Page (`GMAP 395 - Module [#].md`)

Central hub containing:

- Learning objectives and outcomes
- Links to all submodules
- Assignment briefs and due dates
- Required tools and resources
- Progress tracking elements

#### 2. Submodules (`GMAP 395 - Module [#][Letter] - [Title].md`)

**Replace traditional lectures** with focused learning units:

- Specific learning objectives
- Embedded multimedia content
- Self-check exercises
- Links to related materials

#### 3. Assignment Briefs (`GMAP 395 - ASN [#] - Brief.md`)

Comprehensive project instructions including:

- Clear requirements and deliverables
- Assessment criteria and rubrics
- Technical specifications
- Submission guidelines

#### 4. Tutorials (`Tutorials/`)

Step-by-step practical guidance:

- Software-specific instructions
- Workflow demonstrations
- Troubleshooting guides
- Best practices

#### 5. Legacy Content (`Legacy/`)

Previous course materials maintained for reference:

- **Slide files:** Use Advanced Slides plugin for presentation format
- **Video lectures:** Links to recorded content
- **Traditional assessments:** Original quiz and exam materials

### Media Integration

#### Video Content

- **Demo videos:** Embedded via OneDrive/SharePoint links
- **Lecture recordings:** Archived instructional content
- **Student examples:** Portfolio showcases and project walkthroughs

#### Interactive Elements

- **Embedded exercises:** In-line learning activities
- **Progress tracking:** Checkbox completion systems
- **Cross-references:** Bidirectional linking between related concepts


## Course Content Areas

### Module 1: Procedural Modeling + Lighting Systems

- **Submodules:** Game Feel, Procedural Workflows, Node-Based Systems, Lighting Fundamentals
- **Assignment:** Modular asset creation with integrated lighting
- **Focus:** Foundation skills in systematic content creation

### Module 2: Shaders and Materials Development

- **Focus:** Custom shader creation using visual and code-based approaches
- **Integration:** Real-time interactivity and material properties
- **Assessment:** Shader application to previously created assets

### Module 3: Effects + Particle Systems

- **Content:** VFX design principles and particle system implementation
- **Emphasis:** Interactive effects tied to game mechanics
- **Deliverable:** Dynamic visual effects integrated with modular assets

### Module 4: Camera Effects + Post-Processing

- **Topics:** Camera manipulation and post-processing pipelines
- **Balance:** Performance optimization with visual quality
- **Output:** Polished presentation with camera and post-processing integration

### Final Project Integration

Students select **one module for advanced requirements** while meeting basic requirements across all modules, creating a cohesive, polished interactive experience.
